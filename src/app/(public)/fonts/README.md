- Cormorant Garamond 500 normal dan italic: [sumber resmi](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), lisensi `CormorantGaramond-OFL.txt`.
- Manrope variable (rentang yang digunakan 400–600): [sumber resmi](https://github.com/google/fonts/tree/main/ofl/manrope), lisensi `Manrope-OFL.txt`.
