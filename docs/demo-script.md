# Demo lokal sekitar 3 menit

Ini demo fondasi visual dan katalog, bukan skenario WhatsApp end-to-end.

1. Buka `/`. Tunjukkan label data sintetis dan pencarian utama.
2. Isi Bekasi, Rumah, anggaran Rp700 juta. Di katalog, pilih minimal 2 kamar. Hasilnya BKS-001 dan BKS-002.
3. Buka BKS-001. Harga Rp650 juta, dua kamar, luas tanah 90 m², luas bangunan 60 m². Foto masih placeholder.
4. Tunjukkan penjelasan kanal WhatsApp belum aktif. Tidak ada pesan, contact, atau lead baru yang dibuat dari kunjungan website.
5. Cari lokasi yang tidak tersedia untuk memperlihatkan hasil kosong. Hapus filter untuk mengembalikan katalog.
6. Buka `/app`. Dalam mode preview, akses diarahkan ke `/login`.
7. Dari login buka `/preview`. Pilih Sales Andi atau Sari untuk menyaring contoh daftar. Jelaskan ini fixture browser, bukan pembuktian otorisasi.
8. Tunjukkan `/privasi` dan jelaskan bahwa database, AI, handoff, survei, dan WhatsApp live masih menunggu tahap berikutnya.
